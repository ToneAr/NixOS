# NixOS desktop

Flake-based NixOS configuration for a single machine (`tonya-nixos`, user `tonya`),
ported from an Arch Linux install. It sets up KDE Plasma 6 as the main session
and Hyprland as a second option at the SDDM greeter, with Home Manager and
plasma-manager handling the user side.

## Usage

Apply the configuration:

```sh
sudo nixos-rebuild switch --flake /etc/nixos#tonya-nixos
```

Update inputs (nixpkgs, home-manager, ...) and rebuild:

```sh
nix flake update --flake /etc/nixos
sudo nixos-rebuild switch --flake /etc/nixos#tonya-nixos
```

The hostname and username are set in `flake.nix`. `networking.hostName` in
`configuration.nix` has to match the hostname there.

## Flake inputs

| Input            | Purpose                                              |
| ---------------- | ---------------------------------------------------- |
| `nixpkgs`        | `nixos-unstable`, to match the Plasma version the configs were written against |
| `home-manager`   | User environment                                     |
| `plasma-manager` | Declarative Plasma settings, shortcuts and panels    |
| `zen-browser`    | Zen Browser (not in nixpkgs)                         |
| `nix-flatpak`    | Declarative Flathub installs                         |

## Layout

```
flake.nix            inputs, host definition, Home Manager wiring
configuration.nix    main NixOS config
home.nix             Home Manager entry point
system/              machine-level modules
home/                Home Manager modules for the desktop session
addons/           extra packages and opt-in features (system and home)
assets/              files copied from the Arch machine
```

### Top level

| File                | Contents |
| ------------------- | -------- |
| `flake.nix`         | Inputs, host definition, Home Manager wiring; sets the hostname and username |
| `configuration.nix` | Boot, networking, user, Plasma/SDDM, audio, Bluetooth, fingerprint, SSH, containers/VMs, fonts, memory (zram + systemd-oomd) |
| `home.nix`          | Home Manager entry point; imports the home modules, installs YAMIS, links the BreezeX cursor and Plasma assets |

### `system/`

| File                         | Contents |
| ---------------------------- | -------- |
| `hardware-configuration.nix` | Generated by `nixos-generate-config`; don't edit by hand |
| `memory-limits.nix`          | Home Manager module: Zen Browser in a memory-capped `zen.slice`, KWin memory cap |

### `home/` (Home Manager)

| File                | Contents |
| ------------------- | -------- |
| `home-base.nix`     | XDG dirs, session variables, git, delta, direnv |
| `dotfiles.nix`      | ghostty, kitty, waybar, rofi, swaync, wlogout, wallust configs; clones the nvim and fish repos |
| `plasma.nix`        | Plasma theme, shortcuts, KWin rules (from `rc2nix`, pruned by hand) |
| `panels.nix`        | Plasma panels (hand translated) |
| `hyprland.nix`      | Hyprland session |
| `klassy.nix`        | Klassy window decoration config |

### `addons/`

| File               | Type          | Contents |
| ------------------ | ------------- | -------- |
| `applications.nix` | Home Manager  | User applications (including the `kde-rounded-corners` KWin effect) |
| `kde-glass.nix`    | Home Manager  | `kwin-effects-glass` KWin effect, built from source |
| `yamis.nix`        | Package       | YAMIS icon theme, used by `home.nix` |
| `breezex.nix`      | Package       | BreezeX-Dark cursor theme from the GitHub release, used by `home.nix` |
| `flatpak.nix`      | NixOS         | Flathub apps installed by nix-flatpak |
| `wolfram.nix`      | NixOS         | Wolfram/Mathematica integration (`wolfram.enable`, off by default) |
| `wolfie.nix`       | NixOS         | [wolfie](https://github.com/ToneAr/wolfie) CLI installer service (`wolfie.enable`) |

### `assets/`

Files that aren't in nixpkgs, copied from the Arch machine: Plasma widget,
Panel Colorizer presets, dotfiles, wallpapers, Hyprland helper scripts,
Wolfram/wolfie configs, and wallust seed files. See [`assets/README.md`](assets/README.md) for where each one ends up.

## Things to know

- **Plasma panels are fully managed.** plasma-manager rebuilds the panel
  layout from `home/panels.nix` on every activation, so panel changes made in
  the GUI are lost on the next rebuild. Panels for extra screens are behind
  the `dockScreens` flag in the same file.
- **Panel Colorizer styling is applied by hand.** The presets are installed,
  but after the first rebuild each colorizer widget has to load its preset
  once ("separated" for the top panels, "separated WIP" for the folder panel).
- **Some config files stay mutable.** Dotfile directories are linked with
  `recursive = true` so tools can write next to their config. Files that
  wallust and nwg-displays regenerate (wallust colours, `hypr/monitors.conf`)
  are only seeded on first activation and are not managed after that.
- **nvim and fish configs come from GitHub.**
  [ToneAr/.neovim](https://github.com/ToneAr/.neovim) is cloned into
  `~/.config/nvim` and [ToneAr/.fish](https://github.com/ToneAr/.fish) into
  `~/.local/share/fish-config`, with `functions/` and `conf.d/` symlinked into
  `~/.config/fish`. These are normal git checkouts: commit, push and pull in
  place. They're only cloned if missing (by the `clone-config-repos` user
  service), so a rebuild never touches them. home-manager owns
  `~/.config/fish/config.fish`, so the repo's `config.fish` isn't used.
- **Secrets stay out of the store.** fish sources
  `~/.config/fish/secrets.fish` if it exists; create it by hand with
  `chmod 600`.
- **Unfree packages are allowed** (`nixpkgs.config.allowUnfree = true`) for
  Chrome, VS Code, Obsidian, Zoom and others in `addons/applications.nix`.
- **Wolfram is not installed by Nix.** Install it with the official installer
  into `~/Wolfram/Wolfram/<version>`, then set `wolfram.enable = true` in
  `configuration.nix`.
- **Not enabled:** the DisplayLink dock driver (needs a manually fetched
  unfree driver); see the comment in `configuration.nix`.
- Don't change `system.stateVersion` or `home.stateVersion`.
